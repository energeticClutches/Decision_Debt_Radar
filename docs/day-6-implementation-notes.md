## C. Replay architecture

`DDR_LLM_MODE=live|replay|off` (default `replay`; `.env.example` documents it). `get_llm_client()` returns `AnthropicClient` (live with a key, else none), `ReplayDemoClient` (replay) or none (off). In replay mode `get_llm_models` returns stub model names, so a stored `llm_classifications.model` never claims Sonnet. `ReplayDemoClient` is a thin wrapper over `RecordedClient`: the validators, agent_runs metadata, review enforcement, code findings and lifecycle run unchanged. A missing fixture raises `fixture_missing`, which becomes a recorded failure (tests: classification and synthesis).

`backend/demo_fixtures/classify` has 16 files keyed by `input_sha256` (4 requests per scenario), generated by `scripts/build_demo_fixtures.py` from the test stub classifier inside a rolled-back transaction. The script then replays the four scenarios with the product client and fails if any request has no fixture (run: all 16 found). `synthesize/` and `review/` hold copies of the Day-5 hand-authored fixtures. Product code imports nothing from `tests/` (tested). `tests/conftest.py` forces `DDR_LLM_MODE=off` (`live` when an API key is present, for the opt-in live tests).

## D. Frontend architecture

Next.js 16 App Router, client components only, CSS modules plus tokens on `:root` (light, dark by `prefers-color-scheme` and `data-theme`). `lib/api.ts` (one client, `X-Demo-User` from `localStorage`, `ApiError`), `lib/actions.ts` (pure: `can`, `nextAction`, `statusStrip`, `headline`), `lib/format.ts`, `lib/claims.ts`, `lib/useResource.ts`. The workspace loads decision, assessments, recommendations, reviews, syntheses, briefs, traceability, evidence, customer evidence, DQ, analyses, audit and record in parallel; every mutation goes through `perform`, which reloads everything. Presentational components are pure functions of props, so Vitest renders them with `react-dom/server`. No new runtime dependency, no chart or state library, no `dangerouslySetInnerHTML` (grep test). The browser calls `/api/...`; `next.config.mjs` rewrites to `http://127.0.0.1:8000`; CORS is unchanged.

## Deviations / interpretations

1. **Defer and N5.** Defer writes `decision.deferred`, not `assessment.stale`. `stale_reason` reads the latest of the two actions (a fixed sentence for defer). Write paths unchanged.
2. **Approval wording.** The audit reason for an approval was "customer evidence active after the assessment"; it now says approved or rejected (one string in `customer_evidence.py`, not frozen, no test depended on it).
3. **Freshness** is read from `v_evidence_freshness` with the as-of set transaction-locally to the clock's date, and reset after. Null for non-active evidence (the view holds active only).
4. **Provenance of a failed call** (no stored response) is null; a stored response without provenance is `live_model_output`.
5. **Scenario** on the portfolio card is `decision_type` (the API does not expose the scenario key).
6. **Customer gap rows.** No endpoint exposes the Stage-3 gap list, so the UI lists classified themes that have no evidence item ("below the threshold") from the classification counts, without showing any threshold number.
7. **Approve and reject** need a note in the UI (the server does not require one).
8. **Brief creation is disabled after `decided`** (the banner says writes are frozen), although the backend would allow it.
9. **Status strip** has a `partial` kind ranked with `gated` (the brief lists no partial state).
10. **Role check "PM cannot approve"** in the prepared demo has no proposed item, so the Playwright check mocks the customer-evidence response to show one proposed item (display-only), plus a real forced PATCH (403).
11. **Test configuration**: `tests/conftest.py` forces `DDR_LLM_MODE=off` as instructed. No existing test was changed or weakened; the full suite is the old tests plus 24.
12. Foreground order of Playwright: `globalSetup` runs `demo_prepare.py --reset` (about 9 minutes with reseed); `E2E_SKIP_RESET` and `E2E_REUSE_SERVERS` exist for local iteration only.
13. `frontend/vitest.config.mts` uses a `next/link` stub; component tests render to static markup because no DOM library is allowed.
