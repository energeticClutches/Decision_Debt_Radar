# Power BI visuals specification (Day 7)

> **Synthetic data.** FitConnect is fictional. DDI is an evidence-risk heuristic, not a measure of decision quality. LLM-derived figures are "stub, not model output". Generated by `scripts/build_pbip.py` from the same definitions that write the report; if the PBIP report definition does not open in Power BI Desktop, build the visuals below by hand on the semantic model.

Every page footer reads: **Synthetic data · DDI is an evidence-risk heuristic, not a measure of decision quality**

## Data and model

Tables (CSV snapshot in `analytics/powerbi/data`, parameter `DataFolder`): `decisions_lifecycle`, `v_debt_radar`, `v_evidence_health`, `v_evidence_freshness`, `v_coverage_checklist`, `v_nbe_ranking`, `v_traceability_matrix`, `v_agent_quality`, `eval_metrics`. Calculated tables: `Teams`, `DecisionTypes` (slicer sources). Relationships (many-to-one, single direction): `v_debt_radar[decision_id]` -> `decisions_lifecycle[decision_id]`; `v_evidence_freshness[decision_id]` -> `decisions_lifecycle[decision_id]`; `v_nbe_ranking[decision_id]` -> `decisions_lifecycle[decision_id]`; `v_traceability_matrix[decision_id]` -> `decisions_lifecycle[decision_id]`; `decisions_lifecycle[team_id]` -> `Teams[team_id]`; `decisions_lifecycle[decision_type]` -> `DecisionTypes[decision_type]`; `v_evidence_health[team_id]` -> `Teams[team_id]`; `v_evidence_health[decision_type]` -> `DecisionTypes[decision_type]`; `v_coverage_checklist[decision_type]` -> `DecisionTypes[decision_type]`.

### Measures

| Measure | Table | DAX | Format |
|---|---|---|---|
| Decisions | decisions_lifecycle | `COUNTROWS(decisions_lifecycle)` | 0 |
| Scored decisions | decisions_lifecycle | `CALCULATE(COUNTROWS(decisions_lifecycle), decisions_lifecycle[latest_assessment_state] = "scored")` | 0 |
| Insufficient decisions | decisions_lifecycle | `CALCULATE(COUNTROWS(decisions_lifecycle), decisions_lifecycle[latest_assessment_state] = "insufficient_evidence")` | 0 |
| Stale decisions | decisions_lifecycle | `CALCULATE(COUNTROWS(decisions_lifecycle), decisions_lifecycle[assessment_stale] = TRUE())` | 0 |
| Average DDI (scored, current) | decisions_lifecycle | `CALCULATE(AVERAGE(v_debt_radar[ddi_score]), v_debt_radar[assessment_state] = "scored", v_debt_radar[assessment_stale] = FALSE())` | 0.0 |
| Open critical DQ issues | decisions_lifecycle | `SUM(decisions_lifecycle[open_critical_dq_issues])` | 0 |
| Open warn DQ issues | decisions_lifecycle | `SUM(decisions_lifecycle[open_warn_dq_issues])` | 0 |
| Decided while High, Critical or insufficient | decisions_lifecycle | `CALCULATE(COUNTROWS(decisions_lifecycle), decisions_lifecycle[decided_at_risk] = TRUE())` | 0 |
| Days since last assessment | decisions_lifecycle | `MAX(decisions_lifecycle[days_since_assessment])` | 0 |
| Evidence items | v_evidence_freshness | `COUNTROWS(v_evidence_freshness)` | 0 |
| Share within half-life | v_evidence_freshness | `DIVIDE(CALCULATE(COUNTROWS(v_evidence_freshness), v_evidence_freshness[within_half_life] = TRUE()), COUNTROWS(v_evidence_freshness))` | 0% |
| Not evidenced metrics | eval_metrics | `CALCULATE(COUNTROWS(eval_metrics), eval_metrics[status] = "NOT EVIDENCED")` | 0 |
| Measured metrics | eval_metrics | `CALCULATE(COUNTROWS(eval_metrics), eval_metrics[status] <> "NOT EVIDENCED")` | 0 |

### Calculated columns

| Column | Table | DAX |
|---|---|---|
| band_label | decisions_lifecycle | `SWITCH(TRUE(), decisions_lifecycle[assessment_stale] = TRUE(), "Stale (not current)", decisions_lifecycle[latest_assessment_state] = "insufficient_evidence", "INSUFFICIENT EVIDENCE (no DDI)", decisions_lifecycle[latest_assessment_state] = "scored", UPPER(LEFT(decisions_lifecycle[ddi_band], 1)) & MID(decisions_lifecycle[ddi_band], 2, 20) & " band", "No assessment")` |
| decided_at_risk | decisions_lifecycle | `AND(decisions_lifecycle[lifecycle_stage] = "decided", OR(decisions_lifecycle[latest_assessment_state] <> "scored", decisions_lifecycle[ddi_band] = "high", decisions_lifecycle[ddi_band] = "critical"))` |
| age_bucket | v_evidence_freshness | `SWITCH(TRUE(), v_evidence_freshness[age_days] <= 30, "0-30 days", v_evidence_freshness[age_days] <= 90, "31-90 days", v_evidence_freshness[age_days] <= 180, "91-180 days", "Over 180 days")` |
| reduction_label | v_nbe_ranking | `IF(RELATED(decisions_lifecycle[latest_assessment_state]) = "scored", FORMAT(v_nbe_ranking[expected_reduction], "0.0") & " DDI points (potential, not a prediction)", "Resolves blockers (no DDI)")` |
| provenance_label | v_agent_quality | `IF(LEFT(v_agent_quality[model], 5) = "stub:", "stub, not model output", IF(ISBLANK(v_agent_quality[model]), "deterministic stage (no model)", "model output"))` |
| provenance_label | eval_metrics | `IF(eval_metrics[status] = "NOT EVIDENCED", "not measured: no live model", IF(eval_metrics[stub_not_model_output] = TRUE(), "stub, not model output", "deterministic"))` |

### Rules

- **No DDI value for an insufficient decision:** `Average DDI (scored, current)` counts scored, non-stale assessments only; the band label of an insufficient or stale decision is the text `INSUFFICIENT EVIDENCE (no DDI)` or `Stale (not current)`; NBE `reduction_label` shows `Resolves blockers (no DDI)` for them.
- **Neutral colour:** one colour (#4B6584) for all bars; bands are text labels, no red/green verdict.
- **Stale:** a stale assessment is counted by `Stale decisions` and labelled; its number is never part of the average.
- **LLM-derived figures** carry `stub, not model output`; NOT EVIDENCED metrics are listed as such (page 4).
